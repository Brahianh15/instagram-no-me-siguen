# ¿Quién no me sigue en Instagram?

Script de JavaScript para ejecutar desde la consola del navegador (Edge, Chrome, Brave) y ver qué cuentas sigues que no te siguen de vuelta, sin instalar extensiones ni entregar tu contraseña.

## Cómo usarlo

1. Inicia sesión en [Instagram](https://www.instagram.com) desde tu computador.
2. Abre las herramientas de desarrollador presionando **F12** (o clic derecho → **Inspeccionar**).
3. Ve a la pestaña **Consola** (Console).
4. Si es tu primera vez pegando código, escribe `allow pasting` (o `permitir pegar`) y presiona **Enter**.
5. Copia todo el contenido del archivo `script.js`, pégalo en la consola y presiona **Enter**.
6. Espera unos segundos mientras carga las listas. Al finalizar verás el resultado en la misma consola.

## Aviso
Usa este script con moderación. Ejecutarlo muchas veces seguidas puede hacer que Instagram limite temporalmente las consultas de tu cuenta (error 429).
